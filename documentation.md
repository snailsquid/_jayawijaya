# Frontend
Global: 
Use Shadcn for every component
Frontend must be responsive
Neu Brutalist Style

/
Big title in the middle
Start button in the middle

/start
User can choose between exam mode or practice mode.
User can choose which module(s) to use.
User can toggle all modules in a category with a button.
User can categorize modules with custom made categories that acts like folders.
User can name these categories.
User can toggle randomize questions.

/running
User can go to the next and previous question.
Next and previous question buttons must be floating and not blocking the content.
Question grid exist for user to jump to different questions.
Every question in the question grid has a number corresponding to its question number.
A question has 4 states = unseen, unanswered, answered, flagged.
The element in the question grid must reflect those states.
In exam mode user can flag a question to look different in the question grid

/end
User can see their total score.
User can go back to /start or retry 

# Backend
Everything must be local
